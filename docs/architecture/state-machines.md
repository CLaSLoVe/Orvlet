# State ownership and transitions

## State map

| Machine | Owner / identity | Transitions | Invariant / recovery |
| --- | --- | --- | --- |
| Human request | `RequestRun`, task-local run ID | understanding → executing → presenting → verifying; repair may revisit a stage | A selected card is not execution ownership. Cancellation stops only its owning run. Browser acquisition is serialized and released in the run's finalizer. |
| Durable goal / attempt | `WorkRepository`, goal and run IDs | running → completed / partial / waiting / stopped | Saved results survive presentation failure. On process restart, unfinished attempts end and running goals become partial, never completed. |
| Effect receipt | `RequestExecutionLedger`, request revision + normalized operation | absent → running → succeeded / uncertain | Uncertain external side effects are not blindly repeated. Calendar writes require actual user intent and a verifiable receipt. |
| Result operation | artifact ID + artifact revision + job token | Ready → Updating → Ready / Update unavailable / Stopped | Artifact revisions protect values; a separate job token protects cleanup. An older job must not remove the newer job slot, including after cancellation. |
| Result view | `WorkView`, view ID → artifact IDs | visible ↔ hidden; visible/hidden → closed; closed → restored | Closing a view retains its result and independent runtime. Restore projects the retained artifact rather than inventing a generic historical placeholder. |
| Legacy task action | task ID + execution ticket | idle → running → committed / failed / cancelled | Execution and interface revisions are separate lanes. Input edits and disposal invalidate old tickets before another operation. |
| Continuing runtime | artifact ID (legacy task ID only before migration) + generation | running ↔ paused; running → stale → running; running/paused → stopped; explicit resume/restart | Detach cancels pending work and invalidates generation. Repeated pause preserves the original pause time. Native clock sampling does not erase a reducer failure. |
| Countdown | native timer ID + deadline/paused duration | counting ↔ paused; counting → finished; explicit restart → counting | Remaining time derives from the deadline. Unknown controls do nothing. Add-minute cannot restart a finished timer. A hidden view is not a stop command. |
| Page navigation | `BrowserController` instance + `WKNavigation` + navigation generation | provisional → committed → finished / failed; any → disposed or process terminated | A finish/failure from a superseded navigation cannot clear current loading. Observation after an await must still belong to the document. Process termination clears loading/playback and offers reload. |
| Playback intent | browser ID + playback/policy revisions | held by user / preparation / restoration / audio focus → released only when every hold is clear | The four holds are independent. A single asynchronous policy writer applies the latest revision. Page autoplay cannot undo explicit pause. |
| Audio focus | `PlaybackCoordinator`, owner ID + revision | held → switching → owned | Every previous source acknowledges its hold before the next is released. Superseded acquisition must not claim ownership. Only Orvlet-owned pages participate. |
| Session restoration | captured browser instance + restore revision | idle → restoring → restored / failed / cancelled | Do not follow a later active-browser switch. Recheck ownership after asynchronous error cleanup as well as on success. |
| Historical page restoration | task ID + captured browser instance | absent → restoring → open / failed / disposed | Re-read the task after awaits; never retain a mutable array index. An old restoration cannot clear the new restoration job or overwrite its status. |
| Music queue | task ID + music revision | preparing → ready / playing / paused / ended / failed | Queue and playback are activity-owned. User intent, ads, navigation, source handoff and audio focus are separate state. |
| Automatic presentation | source ID + generation + interface ticket | invalidated → preparing → validated / failed | Late generated controls cannot replace another page. Failure preserves the source and retained result. |
| API refresh scheduler | artifact/task ID + last attempt + current job | due → refreshing → scheduled; error → retry | Only fresh verified results update timestamps. Current jobs prevent duplicate refreshes. Job completion reschedules the next deadline. |
| Setup / model access | endpoint/configuration and connection-check task | unchecked → checking → ready / unavailable / permissionNeeded / off | Authorization errors do not fabricate completion. Local fixture checks never require real provider credentials. |
| Extension install | profile host + package UUID + SHA-256 | selected → staged/review → loaded; review → discarded | No execution before approval. Package snapshot and permissions are stable. Links/special files are rejected for folder imports. ZIP decoding belongs to WebKit. |
| Extension lifecycle | profile host + context UUID | enabled ↔ disabled; installed → removed; saved → restored / load error | Mutations are serialized. Disabling unloads rules and scripts for subsequent documents; reload clears prior injected script effects. Removed extensions lose stored data. First page navigation waits for startup restoration. |
